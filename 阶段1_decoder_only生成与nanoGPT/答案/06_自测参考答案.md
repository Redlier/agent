# 阶段 1 自测｜参考答案

1. Tokenizer 把字符串转换为 token/ID，反向可以把 ID 解码回字符串；embedding 使用 ID 查找可学习的连续向量。Tokenizer 规定离散接口，embedding 是模型参数，不负责分段。
2. `x=[3,8,4]`，`y=[8,4,9]`。每个 `x[t]` 对应预测 `y[t]`。
3. 训练时完整目标序列已知，causal mask 允许所有位置在一次前向中并行计算；生成时下一个 token 依赖刚采样出的 token，未来未知，所以通常逐步进行。
4. logits 是未归一化分数；概率是 softmax 后的非负且总和为 1 的分布；token ID 是从词表中选出的整数类别。
5. logits 为 `(2,6,50)`，目标为 `(2,6)`；交叉熵前常摊平为 `(12,50)` 和 `(12,)`。
6. 屏蔽 query 位置右侧的 key 位置，即 `s>t` 的上三角；否则位置 `t` 可以读取真实未来 token 的表示，训练目标泄露。
7. temperature 改变 softmax 前分数的尖锐程度；top-k 固定保留若干最高分候选；top-p 保留累计概率达到阈值的候选。它们只改变推理时的选择，不更新模型参数。
8. 最后位置的 logits 表示给定当前上下文后下一个 token 的分布；其他位置对应已经在上下文中的预测。
9. 每层缓存历史 K 和 V，形状通常含 `(B, heads, T_past, head_dim)`；增量路径与完整重算在相同权重、位置和 eval 条件下应数值近似一致。缓存减少历史 K/V 重算，但仍需读取历史 K 并逐 token 解码。
10. nanoGPT 中，字符数据准备在 `data/shakespeare_char/prepare.py`；模型定义和前向在 `model.py`；训练主循环和 loss 调用在 `train.py`；参数更新也在 `train.py` 的 optimizer step；生成入口在 `sample.py` 和 `model.py` 的 `generate`。实验记录必须包含配置、提示、采样参数、输出与限制，不能只贴输出文本。

评分时，能写出因果关系即可，不要求与本答案逐字一致。
