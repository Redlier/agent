# 阶段 1 参考资料与固定版本

本目录保存阶段 1 实际使用的公开参考资料。论文 PDF 用于个人学习和离线查阅；正式引用时请回到对应的 arXiv/官方页面核对版本。代码仓库保留其原始 LICENSE，不在其中混入本阶段练习代码。

## 仓库版本

`nanoGPT` 当前固定为浅克隆得到的 commit `3adf61e`（2025-11-12）。当前仓库 README 已说明 nanoGPT 属于旧项目并推荐关注其后续项目；本阶段仍选择它，是因为代码短、端到端路径清楚。不要把本地快照当成最新推理框架。

建议只按以下入口阅读：

```text
README.md
config/train_shakespeare_char.py
configurator.py
data/shakespeare_char/prepare.py
model.py: GPTConfig -> CausalSelfAttention -> MLP -> Block -> GPT.forward -> GPT.generate
train.py
sample.py
```

## 阅读时的版本边界

- nanoGPT 的默认字符实验依赖其自己的数据准备脚本；本阶段不自动下载 Shakespeare 数据，也不运行大规模配置。
- nanoGPT 的 attention 可能根据 PyTorch 版本选择 fused/flash 路径或手写 mask 路径；先核对二者的数学语义，再看性能。
- `from_pretrained` 等路径会引入额外依赖；阶段 1 的独立程序只依赖当前 `agent/.venv` 中已有的 PyTorch 和 NumPy。
- 论文中的实验规模、硬件和训练结论不能直接外推到本目录的极小字符模型。
