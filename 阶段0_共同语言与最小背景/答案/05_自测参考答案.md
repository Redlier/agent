# 阶段 0 自测｜参考答案

1. Token 是 tokenizer 切分文本得到的单位；token ID 是词表给该单位分配的整数编号。神经网络需要数值输入，token ID 便于查表并形成数值表示。不同 tokenizer 的切分可能不同。
2. 参数是训练得到并保存在模型中的可学习数值；上下文是当前请求传入、供本次计算使用的信息。普通推理更新上下文内容，不会自动更新模型权重。
3. Logit 是归一化前的原始分数；概率经 softmax 等变换后位于 0–1 且总和为 1。高概率表示模型在当前设置下更倾向某候选，不保证它符合事实。
4. 通常不会。推理用固定参数计算；要改变参数需要进入训练/微调流程并执行优化更新。
5. 损失把预测与训练目标之间的差异按某个目标函数映射成数值，并为优化提供信号。低损失仅表示该目标/数据上的拟合情况，不能证明模型整体可靠。
6. 控制器负责解析和调度模型提出的工具调用、限制流程并回填结果；实际工具代码/服务负责执行具体动作并返回观察结果。模型发出调用请求不等于调用已执行。
7. 上下文窗口是一次处理可用输入的容量边界；参数是模型训练得到的权重；外部持久记忆由应用系统存储，并在之后按需检索或重新提供。
8. 不能。模型文本是声明，文件变更需要程序对文件系统执行写入，并通过检查文件内容或差异验证。
9. 10 个数，通常可表示 5 个样本、每个样本含 2 个特征。
10. 清空梯度 → 前向预测 → 计算损失 → `loss.backward()` 计算梯度 → `optimizer.step()` 更新参数。不同实现可能把前向与损失写成更多行，但因果顺序相同。
