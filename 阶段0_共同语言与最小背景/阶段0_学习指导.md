# 阶段 0｜共同语言与最小背景

> 本阶段回答四个问题：模型在处理什么？模型怎样产生预测？训练怎样改变模型？Agent 系统比单个模型多了什么？

## 本阶段的位置

这是进入 Transformer 学习前的热身阶段。重点是先建立稳定的概念地图和 PyTorch 基本阅读能力，不追求推导完整的神经网络数学，也不深入 Transformer 内部。

完成阶段 0 后，你应当能够用自己的话说明：

1. 文本如何经过 token 与 token ID 变成模型可以处理的输入。
2. 模型参数、输入、预测结果、损失分别是什么。
3. 训练和推理怎样区分；训练时什么会变化，推理时什么保持固定。
4. Agent 为什么不仅是一个模型，以及工具调用为什么需要程序参与。
5. 一个最小 PyTorch 训练循环中，数据、模型、损失、梯度和优化器各自负责什么。

## 时间安排

建议用 5 次学习、总计约 6–9 小时。每次约 60–100 分钟，可分散到一周完成。若 Python 或函数/列表/字典还不熟，先把代码练习拆短；不要因代码语法卡住就跳过概念。

| 学习次序 | 内容 | 建议时间 | 完成标志 |
|---|---|---:|---|
| 1 | 模型、token、参数、训练和推理 | 60–90 分钟 | 能画出文本进入模型后的最简流程 |
| 2 | 向量、矩阵、概率、损失和梯度直觉 | 75–100 分钟 | 能解释“预测错了多少”以及参数为何要调整 |
| 3 | 从 LLM 到 Agent：系统架构与边界 | 60–90 分钟 | 能画出模型、控制器、工具、环境之间的数据流 |
| 4 | PyTorch 张量与模型语法 | 75–100 分钟 | 能读懂张量形状、`nn.Module` 和前向计算 |
| 5 | 自动求导、优化器和小型训练练习 | 90–120 分钟 | 能补全并运行一个线性回归训练循环，解释每一步 |
| 6（可选） | 闭卷复述与错题回看 | 30–60 分钟 | 自测达到通过标准，能说明仍不确定的点 |

## 推荐学习顺序

1. 先读 [01_模型与训练推理学案](01_模型与训练推理学案.md)。暂时不要背术语，先理解每个概念在流水线里的位置。
2. 再读 [02_数学直觉学案](02_数学直觉学案.md)。只学后续会反复遇到的矩阵、概率、损失和梯度直觉。
3. 接着读 [03_LLM与Agent架构学案](03_LLM与Agent架构学案.md)，把“一个模型”和“一个能行动的系统”分开。
4. 最后做 [04_PyTorch入门学案](04_PyTorch入门学案.md)，边读边运行 `代码/01_tensor_warmup.py`，再独立补完 `练习/01_补全训练循环.py`。
5. 完成后先闭卷写 [05_阶段自测与复盘](05_阶段自测与复盘.md)，再查看 `答案/` 中的参考材料。先尝试再看答案，效果更好。

## 学习方法

每个概念用四句话记录：**它是什么、它接收什么、它产出什么、它不代表什么**。例如：损失是衡量预测与目标差异的标量；接收预测和目标；产出一个训练信号；它不等于完整的模型质量。

遇到代码时，按“输入 → 形状 → 运算 → 输出 → 参数有没有变化”追踪。不要一开始就记 API 名称。一个术语若无法举例，就先不要认为已经掌握。

## 边界：现在学什么，留到后面什么

本阶段会建立 token/token ID 的概念，但不学习分词算法或 tokenizer 的实现；会知道 Transformer 是一种模型架构，但不讲自注意力公式、位置编码或 decoder-only 生成细节；会认识 logits、概率与采样的关系，但不系统比较 temperature、top-k 和 top-p；会画出 Agent 工具循环的组件，但不接 API 或执行真实系统命令。

这些内容分别留到阶段 1 的生成机制、阶段 3 的工具循环和阶段 4 的 coding agent。当前目标是拥有理解它们所需的共同语言。

## 完成本阶段的验收

- 可以不看资料画出“文本 → token ID → 模型预测 → 损失/生成结果”的示意图。
- 能说明训练时参数依据数据与目标而更新；推理时参数固定，只根据当前输入计算输出。
- 能解释张量形状、模型前向传播、损失、`backward()` 与 `optimizer.step()` 的基本关系。
- 能指出 Agent 还需要状态/上下文管理、控制逻辑、工具执行和结果验证。
- 能运行线性回归练习，并观察训练损失整体下降；若没有下降，能检查学习率、梯度清零和数据/目标是否正确。
- 阶段自测至少 8/10；错题能用自己的话修正，而非只记选项。

## 环境与建议资源

练习默认 CPU 即可，不需要 GPU、模型下载或 API key。本学习目录使用独立环境 `agent/.venv`，编辑器和终端需选择其中的解释器。环境的选择、安装与运行方式见 [环境使用说明](../环境使用说明.md)。

- [Build the Neural Network](https://docs.pytorch.org/tutorials/beginner/basics/buildmodel_tutorial.html)
- [Automatic Differentiation](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)
- [Optimizing Model Parameters](https://docs.pytorch.org/tutorials/beginner/basics/optimization_tutorial.html)

本阶段只需读官方教程中张量、模型、autograd 和优化循环的入门部分。官方页面会随 PyTorch 版本更新；本目录示例尽量使用长期稳定的基础接口。
