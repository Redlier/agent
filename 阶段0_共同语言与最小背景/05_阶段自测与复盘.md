请先闭卷作答，再对照 `答案/05_自测参考答案.md`。每题 1 分。解释题按关键关系正确得分，不要求逐字一致。

## A. 概念自测

1. token 和 token ID 分别是什么？为什么模型一般不直接“读取汉字”？
2. 模型参数与当前对话上下文有什么区别？
3. Logit 与概率有什么区别？
4. 推理时模型生成了新对话，通常会自动改变参数吗？说明原因。
5. 训练中的损失函数负责什么？损失小是否证明模型整体可靠？
6. 一个 Agent 的工具调用请求由谁实际执行？至少写出控制器和工具各自的一项职责。
7. 上下文窗口、模型参数和外部持久化记忆有什么不同？
8. 若模型提出“文件已经修改”，但系统没有执行任何文件工具，我们能否据此断定文件已修改？为什么？
